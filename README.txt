🚀 Loop of Legends - Installation Guide

1. Open XAMPP and start Apache & MySQL.

2. Open http://localhost/phpmyadmin in your browser.

3. Create a database named: loop_of_legends

4. Click 'Import' → Choose the file: Queries/loop_of_legends_complete.sql

5. Ensure this project folder is placed in: C:\xampp\htdocs\loop-of-legends

6. Open your browser and visit:
   - Website: http://localhost/loop-of-legends
   - Admin Panel: http://localhost/loop-of-legends/admin.php

For complete details, screenshots, and architecture, refer to README.md!
